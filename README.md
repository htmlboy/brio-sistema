# Brío sistema

Static publication for https://sistema.briorol.com/.

Home, /reglas/ and /jugar-en-persona/ include build-time HTML; React hydrates the controls.

This repository contains compiled website files. The application source is maintained separately. Changes pushed to main are published by GitHub Pages. Firebase provides the online services; no hosting is provided by Netlify.

This site does not use Firebase configuration. No service-account keys or publishing tokens are included.
